<h1 align="center">CryptoKnightX</h1>

<div align="center">
<a href="https://www.gnu.org/software/bash/" target="_blank"><img src="https://badgen.net/badge/Made with/Bash/green?icon"></a>
<img src="https://badgen.net/badge/Version/0.0.8/red?icon">
<a href="LICENSE" target="_blank"><img src="https://badgen.net/badge/License/MIT/black"></a>
</div>

<div align="center">
<p>CryptoKnightX é uma ferramenta CLI para criptografar arquivos utilizando GnuPG.</p>
<p>Mantenha a segurança e privacidade de seus arquivos importantes com simplicidade em seu terminal.</p>
</div>

<!---DEPENDENCIAS--->

<br>
<h2 align="center">Dependências</h2>
<p>Dependências necessárias para utilizar o software:</p>
<ul>
   <li><b>UNIX Tar</b></li>
   <li><b><a href="https://www.gnu.org/software/bash/" target="_blank">Bash</a> 4+</b></li>
   <li><b><a href="https://gnupg.org/" target="_blank">gnupg</a> 2.2.7+</b></li>
</ul>

<br>
<h2 align="center">Como instalar?</h2>
<p>Use um dos comandos logo abaixo para instalar o CKX:</p>

<p><code>git</code>:</p>
<pre>git clone https://github.com/ghostkill73/CryptoKnightX && cd CryptoKnightX && chmod +x ckx</pre>
<br>
<p><code>wget</code>:</p>
<pre><code>wget https://raw.githubusercontent.com/ghostkill73/CryptoKnightX/main/ckx && chmod +x ckx</code></pre>
<br>
<p><code>curl</code>:</p>
<pre><code>curl -L https://raw.githubusercontent.com/ghostkill73/CryptoKnightX/main/ckx > ckx && chmod +x ckx</code></pre>
<br>
